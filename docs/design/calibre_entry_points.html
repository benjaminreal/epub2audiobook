Outside the main window

⌨ Keyboard shortcutDefault set in the plugin code. The user can rebind it under Preferences → Shortcuts.
⚙ Customize pluginPreferences → Plugins → Customize. Calibre wraps your settings widget in a scrolling dialog with OK and Cancel.
🧩 Your own dialogsAny Qt window you open from the action: wizards, tables, progress dialogs.
🖱 Drag and dropDrop books or files onto the plugin's button (accepts_drops).
🔁 Convert dialogOnly for a different plugin type, a conversion output plugin. "M4B" would appear as an output format there, as KFX Output's format does.
✕ No plugin UI hereE-book viewer, content server (web UI), Book details panel layout, docked side panels (no supported API).
